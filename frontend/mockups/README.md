# Design mockups

Static, non-interactive design mockups of the RecoverAI control plane (exported
from Google Stitch and rebranded). They are **not** part of the running app:
the live UI is `../index.html`, built from `../views/` by `../gen_spa.py`.

Pages link to each other where a real counterpart exists and to the live
control plane for marketing/dashboard links; the remaining `#` links
(Customers, Docs, Support, Pricing, Careers, ...) are design placeholders with
no destination. Sample figures match the seeded golden scenario (8 failed
payments, ₹14,000 at risk).

`../stitch_imports/` keeps the untouched original Stitch exports for reference.
